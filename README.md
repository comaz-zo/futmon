# Futmon mobile and webdb

This repository contains two main applications, each located in its own sub-folder:

## 1. conecofor_mobile

This folder contains the **Conecofor Mobile** application.  
It is designed to be used on mobile devices, providing field users with an interface to collect, view, and manage data remotely. The application is built to work efficiently on smartphones and tablets, offering features such as offline data entry, synchronization with the main database, and user-friendly navigation optimized for touchscreens.

**Key Features:**
- Mobile-optimized interface for easy data entry in the field
- Support for offline mode with later synchronization
- Integration with the main Conecofor database

## 2. conecofor_webdb

This folder contains the **Conecofor WebDB** application.  
It serves as the web-based database management system for Conecofor data. This application is intended for use by administrators and analysts, providing tools for viewing, editing, and analyzing the collected data through a web browser. It includes advanced filtering, reporting, and user management features.

**Key Features:**
- Web interface for managing and analyzing Conecofor data
- Tools for data import/export, reporting, and administration
- User and permissions management
